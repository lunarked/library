# Working on this repo

- Push changes straight to `main`. Do not open pull requests or ask before pushing; the owner has approved direct pushes.
- The site is published with GitHub Pages from `main` at https://lunarked.github.io/library/.
- New tools go in `tools/`, stories in `stories/`, Amazon FBA pages in `fba/`, e-scooter operations pages in `escooter/`, network planning pages in `planning/`, manufacturing pages in `manufacturing/`. Workbook pages in `fba/`, `escooter/`, `planning/` and `manufacturing/` are built from `fba/src/` (engine) and each folder's `src/specs/` (plus `src/common.js` when a folder has one): run `python3 fba/src/build.py`. Add each new page to `index.html` (see the next point).
- The home page (`index.html`) leads with the stories and keeps tools and workbooks in a compact panel beside them (below them on phones). Add a story to the Stories list, newest event first: its title, the year of the event, and the one question the story answers, taken from the story page. Add a tool to the Tools list as one line. Add a workbook inside its set under Workbooks; a new set is one more `<details>` row. The counts update themselves. Keep the page plain: white, text only, no thumbnails, no hero, no follow, contact or resume links. Stories stay first and visibly different from the tools.
- Never use em dashes in any page or text.
- Every workbook page has an Excel version next to it (`<name>.xlsx`, Download Excel button). Excel files are generated by `xl/` from each page's sample data: `python3 xl/run.py <fba|escooter|planning|manufacturing|standalone> [function]`. Production planning is built by `manufacturing/src/excel/build_production_planning.py`. Rebuild the Excel file whenever a workbook's logic changes, then run `python3 fba/src/build.py`.
- Every story has a share image and share tags, so a link shows a preview when it is posted. The image is `og/<slug>.png` (1200 x 627: a kicker, one big number, one caption). The tags sit in the story's `<head>` between `<!-- share:start -->` and `<!-- share:end -->`. Both are generated, so do not edit them by hand: add the story to `og/src/cards.json` (slug, title, description, kicker, hero, caption) and run `node og/src/build.js`. It needs Playwright and Chrome; when Google Fonts is blocked, set `OG_FONT_DIR` to a folder of `@fontsource` packages (`archivo`, `jetbrains-mono`). The big number must come from the story itself.
